## 📌 Overview

A Python OOP demonstration implementing a restaurant menu management system with franchises, time-based menu availability, and bill calculation. Originally built as a Codecademy learning project — kept as a programming milestone.

---

## ✨ Features

- 🍝 **Menu class** — items with prices, start/end times
- 🏪 **Franchise class** — locations with address and menus
- 🏢 **Business class** — restaurant group with multiple franchises
- 🧾 **Bill calculation** — total based on purchased items
- ⏰ **Availability logic** — time-aware menu filtering

---

## 🚀 Quick Start

```bash
python3 TimeleyTables.py
```
